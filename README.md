# Embedded AI Image Classification (TinyML)

## Overview

This project demonstrates the development and deployment of a lightweight image classification model using TinyML techniques. The objective was to build an efficient machine learning solution capable of running on resource-constrained embedded hardware while maintaining acceptable accuracy and real-time performance.

The project covers the complete TinyML workflow including data preparation, model training, optimization, deployment, and hardware validation.

---

## Features

* Lightweight image classification model
* TinyML-based deployment workflow
* Data preprocessing and model training
* Real-time inference on embedded hardware
* Performance evaluation and optimization
* Analysis of accuracy, latency, and memory usage
